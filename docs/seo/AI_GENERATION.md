# AI-заполнение SEO товаров

Вкладка SEO карточки `/Ameise/goods/{id}` позволяет получить черновики H1, Meta title,
Meta description, краткого и большого SEO-текста через Timeweb AI Gateway.
Генерация возвращает текст в форму; запись в базу выполняется обычной кнопкой
сохранения SEO после проверки редактором.

## Подключение

В окружении приложения задайте:

```dotenv
GOODS_SEO_AI_ENABLED=true
GOODS_SEO_AI_MODEL=EXACT_TIMEWEB_MODEL_ID
GOODS_SEO_AI_API_KEY=TIMEWEB_API_KEY
GOODS_SEO_AI_TOKEN_PARAMETER=max_tokens
GOODS_SEO_AI_TIMEOUT_SECONDS=45
```

Если уже настроен `AI_TIMEWEB_LOCAL_RU_API_KEY`, отдельный `GOODS_SEO_AI_API_KEY`
можно оставить пустым: используется существующий ключ. Идентификатор модели
нужно указать явно, выбрав доступную для этого ключа модель с поддержкой Chat
Completions. Для обычных моделей используется `max_tokens`; для моделей,
требующих `max_completion_tokens`, задайте это значение в
`GOODS_SEO_AI_TOKEN_PARAMETER`. Допустимы только эти два имени параметра.
Модель и ключ не передаются из браузера.
После изменения окружения обновите кеш конфигурации обычным способом:
`php artisan config:cache`.

Для русскоязычных SEO-черновиков подходит доступная в проверенном каталоге
`yandex/yandexgpt-lite` с параметром `max_tokens`: в публичном каталоге Timeweb
она указана как YandexGPT 5.1 Lite без обязательных размышлений. Это выбор
для редакторской задачи, а не подтверждение места обработки данных.
Источники: [AI Gateway](https://timeweb.cloud/docs/ai-agents/api-usage/ai-gateway),
[каталог моделей и параметров](https://timeweb.cloud/services/ai-gateway),
[модели с размышлениями](https://timeweb.cloud/docs/ai-agents/pricing/models).
Проверка доступности `GET /v1/models` не расходует токены генерации. Перед
production-деплоем дополнительно проверена реальная генерация H1 на синтетическом
товаре через явный режим `--live`, описанный ниже.

## Production через GitHub Actions

Основной workflow `.github/workflows/main.yml` проверяет SEO API и updater,
затем при деплое включает `GOODS_SEO_AI_ENABLED=true`, задаёт модель
`yandex/yandexgpt-lite`, параметр `max_tokens` и таймаут 45 секунд.
Updater меняет только эти четыре настройки; существующие ключи остаются на VPS.
До maintenance проверяется наличие корректного `GOODS_SEO_AI_API_KEY` либо
`AI_TIMEWEB_LOCAL_RU_API_KEY`. При отсутствии ключа деплой останавливается до
переключения приложения. После обновления config cache выполняется проверка
активной конфигурации и защищённого POST-маршрута без обращения к провайдеру.

Для явной проверки одного реального запроса на синтетическом товаре:

```bash
php scripts/check-production-goods-seo-ai.php /absolute/path/to/app --live
```

Режим `--live` делает один платный запрос H1, не сохраняет записи и выводит
только статус и длину результата. Обычный deploy этот режим не запускает.

Это отдельная интеграция для редакторских черновиков товаров. Настройки
`AI_SALES_*`, `AI_TIMEWEB_*_ENABLED` и synthetic-only ограничения AI Sales
не требуется менять. По умолчанию SEO-интеграция выключена. Платные запросы
выполняются только по нажатию кнопки AI пользователем; автоматических повторов нет.

## API и данные

`POST /api/goods/{good}/seo/generate-ai` принимает:

```json
{
  "field": "h1",
  "context": {
    "focus_keyword": "яблочный пектин",
    "keywords": ["пектин для производства"]
  }
}
```

Поля генерации: `h1`, `meta_title`, `meta_description`, `short_seo_text`, `seo_text`.
Ответ: `{"field":"h1","value":"Яблочный пектин для пищевого производства"}`.
Все значения — обычный текст; большой текст сохраняет абзацы и переводы строк.
HTML и исполняемое содержимое удаляются, незавершённые ответы отклоняются.

Контекст может включать `focus_keyword`, `h1`, `meta_title`, `meta_description`,
`short_seo_text`, `seo_text`, `semantic_core`, `keywords`, `search_queries`,
`min_order`, `delivery_note`, `payment_note`. Незнакомые поля контекста отклоняются.
Текущие значения формы имеют приоритет над сохранённым SEO. К ним добавляются
название и описание товара, страна и названия категорий из базы. Связанные
контакты, контрагенты, закупки, продажи, цены, внутренние заметки и прочие
атрибуты модели в запрос не включаются. Инструкции запрещают придумывать факты.

Генерация доступна подтверждённым пользователям с типом `employee` либо ролью
`admin` guard `crm`, кроме заблокированных пользователей. Ограничение —
10 запросов в минуту на пользователя. Передача выполняется только на
`https://api.timeweb.ai/v1/chat/completions`: TLS, без перенаправлений, с
`store=false`, таймаутом 5–60 секунд, пределом входного JSON 64 КиБ, ответа
256 КиБ и до 4096 выходных токенов. Сервис не журналирует ключи, запросы,
ответы или ошибки провайдера.

`GET /api/goods/{good}/seo` дополнительно возвращает безопасные метаданные
`ai_generation: {available, message}` для отображения состояния подключения.
Готовность означает наличие конфигурации; отдельной проверки баланса или
доступности модели этот запрос не делает.

Ошибки имеют безопасные `message` и `code`: `seo_ai_not_configured` (503),
`seo_ai_rate_limited` (429), `seo_ai_timeout` (504),
`seo_ai_provider_error` / `seo_ai_invalid_response` (502),
`seo_ai_input_too_large` (422). Ошибки валидации используют стандартный ответ
Laravel 422. Генерация, включая неудачную, не сохраняет SEO и не отправляет IndexNow.

# AI-перевод названий продуктов

В `/Ameise/products` → Products → «Создать продукт» введите русское название,
при необходимости выберите категорию и нажмите «Заполнить переводы AI».
Один запрос заполняет пустые поля 18 иностранных языков. Введённые вручную
значения сохраняются. Переводы можно отредактировать и затем сохранить
обычной кнопкой «Создать». Сам перевод не создаёт продукт и не меняет базу.

При изменении исходного названия, категории или закрытии формы ожидающий
ответ отменяется в браузере и не применяется. Отмена в браузере не гарантирует
отмену уже начатой генерации у провайдера. Автоматических повторов нет.

## Подключение

По умолчанию используются настройки существующего AI-заполнения SEO товаров:
`GOODS_SEO_AI_ENABLED`, `GOODS_SEO_AI_API_KEY`, `GOODS_SEO_AI_MODEL`,
`GOODS_SEO_AI_TOKEN_PARAMETER`, `GOODS_SEO_AI_TIMEOUT_SECONDS`.
Резервный источник ключа — `AI_TIMEWEB_LOCAL_RU_API_KEY`.

Для отдельной конфигурации переводов задайте нужные переопределения:

```dotenv
PRODUCT_TRANSLATIONS_AI_ENABLED=true
PRODUCT_TRANSLATIONS_AI_API_KEY=TIMEWEB_API_KEY
PRODUCT_TRANSLATIONS_AI_MODEL=EXACT_TIMEWEB_MODEL_ID
PRODUCT_TRANSLATIONS_AI_TOKEN_PARAMETER=max_tokens
PRODUCT_TRANSLATIONS_AI_TIMEOUT_SECONDS=45
```

Модель должна поддерживать Chat Completions и нужные языки. Качество отраслевых
терминов следует проверить на примерах каталога. Допустимы параметры лимита
токенов `max_tokens` и `max_completion_tokens`, таймаут — 5–60 секунд.
После изменения окружения обновите кеш: `php artisan config:cache`.
Настройки AI Sales изменять не требуется.

## API

`POST /api/products/translate-ai`:

```json
{"rus":"Яблочный пектин","category_id":null,"languages":["eng","de"]}
```

Ответ:

```json
{"translations":{"eng":"Apple pectin","de":"Apfelpektin"}}
```

Языки соответствуют колонкам продукта: `eng`, `zh`, `hi`, `es`, `fr`, `ar`,
`po`, `ur`, `idn`, `de`, `ja`, `fa`, `vi`, `tu`, `ko`, `it`, `nl`, `he`.
`po` — португальский, `tu` — турецкий, `idn` — индонезийский.
Провайдер получает только русское название, название выбранной категории
и список целевых языков. Ответ должен содержать весь запрошенный набор без
лишних ключей: каждый перевод — непустой обычный текст до 255 символов.
Неполные, оборванные и некорректные ответы отклоняются целиком.

Доступ: подтверждённый сотрудник (`employee`) или администратор (`admin`, guard
`crm`), кроме заблокированных пользователей. Лимит — 10 запросов в минуту на
пользователя. Настройки и ключи остаются на сервере; ошибки провайдера заменяются
сообщениями без содержимого запроса или секретов. Статусы: 422 — неверные
данные, 503 — нет настройки, 402 — баланс, 429 — лимит, 504 — таймаут,
502 — ошибка провайдера или некорректный перевод.

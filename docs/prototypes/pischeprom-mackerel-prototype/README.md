# Скумбрия — полный исходный прототип для интеграции

Это полный комплект исходников страницы, передаваемый вместе с CODEX_TASK.md.
Распакуйте архив целиком. Пути ниже отсчитываются от папки pischeprom-mackerel-prototype.

## Состав

- dist/index.html — вся вёрстка, статья, инфографика, каталог, SEO-метаданные и видимая атрибуция фотографий.
- dist/styles.css — стили для компьютера и мобильных устройств.
- dist/app.js — навигация и раскрытие разделов при переходе по якорям.
- dist/assets/mackerel-hero.jpg — фотография атлантической скумбрии.
- dist/assets/mackerel-smoked.jpg — фотография блюда из копчёной скумбрии.
- dist/assets/photo-sources.json — авторы, ссылки на источники, условия лицензий и описание изменений.
- integration/catalog-snapshot.json — сопоставление четырёх карточек с Good.id; снимок каталога от 8 октября 2026.
- integration/CODEX_TASK.md — задание на перенос в Laravel + Vue + Inertia.
- SHA256SUMS — контрольные суммы всех перечисленных файлов и этого README.

## Продолжение в PhpStorm / Codex

Работать в уже созданной ветке codex/mackerel-class-landing.
Прочитать integration/CODEX_TASK.md, затем перенести фактическую вёрстку из dist.
Использовать найденные в проекте публичные сервисы цен, наличия и актуальных URL.
Учесть выполненный аудит SSR и sitemap. Новые выводы из рабочего проекта имеют приоритет
над снимком публичных данных от 8 октября 2026.
Сохранить все сделанные в ветке изменения и результаты проверок; не начинать работу заново.
Публикация в основном магазине не входит в этот перенос.

Например, комплект можно разместить в docs/prototypes/pischeprom-mackerel-prototype/
внутри рабочего проекта и передать Codex эту папку как источник дизайна и содержания.
Копировать dist целиком в production public/ не нужно: следует выполнить интеграцию,
описанную в задании, сохранив существующие сервисы и компоненты магазина.

## Локальный просмотр

Откройте dist/index.html в обычном браузере. Сборка и установка зависимостей не нужны.
Вёрстка, изображения и раскрывающиеся разделы работают локально; товарные ссылки ведут
в действующий интернет-магазин и требуют подключения к сети.
В прототипе нет live-подключения к базе и нет копий текущих цен/остатков.

Опубликованный визуальный образец:
https://pischeprom-mackerel.orange-basil-8502.chatgpt.site
Доступ к нему может требовать входа владельца; все необходимые исходники уже в этом архиве.

## Происхождение и лицензии

Архив содержит точную копию восьми файлов исходного опубликованного прототипа
из коммита dd4d261e2c77f8ffef3200e5a9c96fb503bfaca3; код и дизайн при упаковке не изменены.
Файлы .git, .openai, окружение хостинга и служебные данные не включены.

Фотографии: Petar Milošević — CC BY-SA 4.0; Jocian — CC BY-SA 3.0.
Сохраните атрибуцию и условия лицензий. Изображения уменьшены и сжаты для сайта,
кадрирование выполняется CSS. Поля width/height в photo-sources.json описывают оригиналы;
включённые JPEG имеют размеры 1500×1051 и 1100×825 соответственно.

В прототипе установлен noindex, nofollow. Этот режим нельзя автоматически переносить
на индексируемую страницу основного магазина: используйте действующий SEO-модуль.

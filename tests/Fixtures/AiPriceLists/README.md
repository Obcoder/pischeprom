# Обезличенные fixtures прайс-листов

Бинарные fixtures не хранятся в Git. `Tests\Support\AiPriceListFixtureFactory` создаёт во временном каталоге:

- XLSX с одной и несколькими вкладками, merged cells;
- XLS с формулой (парсер читает cached/raw data и не вычисляет формулу);
- CSV UTF-8 и Windows-1251;
- DOCX с таблицей;
- текстовый, сканированный и смешанный PDF (текстовая + сканированная страницы);
- PNG, имитирующий вход в OCR;
- пустой, повреждённый, защищённый паролем и MIME-spoofed файл;
- TIFF для проверки многослойного преобразования через `libtiff-tools` (тест пропускается,
  если системные бинарники отсутствуют).

Все названия и цены синтетические. Внешние API в тестах подменяются fake-провайдерами.
